# Timerfoto

Un'applicazione timer con funzionalità di foto e gestione della conoscenza basata sulla teoria dei grafi.

## Funzionalità

- Timer personalizzabile con countdown
- Caricamento foto
- **Cervello Grafologico**: Sistema di gestione della conoscenza basato sulla teoria dei grafi
  - Creazione di nodi per discussioni e codice
  - Visualizzazione del grafo della conoscenza
  - Connessioni tra nodi per creare relazioni
  - Esportazione dei dati del grafo
- Condivisione messaggi con amici
- Notifiche sonore

## Cervello Grafologico

Il "Cervello Grafologico" è un sistema intelligente basato sulla teoria dei grafi che permette di:
- Salvare discussioni e frammenti di codice come nodi del grafo
- Creare connessioni tra concetti correlati
- Visualizzare la rete di conoscenze accumulata
- Esportare l'intera struttura del grafo
